## Issue convention

Example:

`[QUIZ-004] Generate random quiz from question bank`

Every feature issue should include:
- Requirement ID.
- Scope.
- Acceptance Criteria.
- Related screens.
- Expected API/DB impact if known.
- Test expectation.
- Dependencies / blockers.

## Branch protection recommendation

For `main`:
- Require Pull Request.
- Require status checks.
- Block force push.
- Block deletion.
- Require conversation resolution if the team uses review comments.
