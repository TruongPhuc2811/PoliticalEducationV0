## 4. Weekly current-window correction

`WeeklyQuestionRepository.findCurrentAt(@Param("now") LocalDateTime now)` is module-local JPQL with one authoritative application-supplied business instant:

```jpql
q.periodOpensAt <= :now
AND q.periodClosesAt > :now
```

This preserves the accepted half-open Weekly period `[periodOpensAt, periodClosesAt)`. It does not use database time, native SQL, lifecycle status, scheduler behavior, or speculative resolution for theoretically corrupt overlapping periods.
