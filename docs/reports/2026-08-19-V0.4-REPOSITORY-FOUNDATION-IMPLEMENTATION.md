## 3. Repository strategy

Each repository is a module-owned `JpaRepository<Entity, Long>` in `vn.pes.<module>.repository`. There is no global repository/DAO module, generic base repository, custom persistence hierarchy, service, controller, DTO, mapper, transaction flow, query projection, or native SQL. Repositories operate only on their own module entities.
