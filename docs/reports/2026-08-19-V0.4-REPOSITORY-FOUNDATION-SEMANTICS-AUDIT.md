## 5. Critical audits

### Account

Only username identity methods exist. No password-hash or combined credential query exists.

### Invitation lock

`InvitationRepository.findByCodeHash(byte[])` returns `Optional<Invitation>` and is annotated `@Lock(LockModeType.PESSIMISTIC_WRITE)`. It accepts only the deterministic digest, not a raw code. The later registration use case must invoke it inside its transaction; this repository does not establish that boundary.

### Assignment-history half-open correction

The prior derived method constrained only `accountId` and `effectiveFrom <= :effectiveAt`; it did not enforce `effectiveTo IS NULL OR effectiveTo > :effectiveAt` and therefore was not a point-in-time assignment lookup. It was replaced with one module-local JPQL method. Parentheses ensure account/time predicates apply to both end-time branches. Ordering is deterministic if corrupt overlapping data exists; the accepted application invariant remains that ranges do not overlap.

### Handbook pagination

One `Page`/`Pageable` method exists and it requires both category and supplied publication status. A future public use case must pass `PUBLISHED`; no FULLTEXT search was added.

### Quiz

The active-attempt lookup includes account, config, and an explicit `QuizAttemptStatus` parameter. Its use for resume must pass `ACTIVE`; the generated-column unique guard remains the integrity authority. Attempt and result lists retain exact account/config predicates. No Competition entity, PASS filter, grading, ranking, or insertion logic is present.

### HCM and Weekly

HCM uses caller-supplied `businessDate`, explicit status, `id ASC`, and `First`; it does not use database time. Weekly correctly uses `LessThanEqual` for opens and strict `GreaterThan` for closes, preserving the exclusive close boundary.

### Competition and Popular View

The Competition lookup uses exactly `(periodId, accountId, quizConfigId)` and imports no Quiz entity. Popular View uses exactly `(contentDomain, contentId, viewDate)` and contains no increment implementation.
