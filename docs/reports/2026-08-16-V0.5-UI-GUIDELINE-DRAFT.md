## 10. Guideline strategy

1. Dùng semantic role thay vì mô tả màu rời rạc.
2. Tách stable pattern khỏi candidate brand value và implementation detail.
3. Giữ shared identity nhưng phân biệt User/Admin interaction density.
4. Đặt OI boundary ngay tại quiz/ranking/dashboard/file/auth pattern bị ảnh hưởng.
5. Chuẩn hóa 15 pattern families, không thiết kế React API.
6. Dùng P0 bundle/resource evidence làm guidance, không đặt budget mới.
